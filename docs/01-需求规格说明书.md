## M1 项目台账管理

### M1-1 新建/编辑项目
**输入字段**

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| 项目编号 | 是 | 文本 | 唯一，如 `PRJ-2026-001` |
| 项目名称 | 是 | 文本 | |
| 项目地址 | 否 | 文本 | |
| 建设单位 | 否 | 文本 | 甲方 |
| 施工单位 | 否 | 文本 | 我方或承包方 |
| 监理单位 | 否 | 文本 | |
| 项目经理 | 是 | 文本 | |
| 联系电话 | 否 | 文本 | |
| 合同金额 | 否 | 数值 | 元，记录用不参与计算 |
| 开工日期 | 是 | 日期 | |
| 计划竣工日期 | 是 | 日期 | |
| 实际竣工日期 | 否 | 日期 | |
| 项目状态 | 是 | 枚举 | 见字典 ENUM-01 |
| 备注 | 否 | 长文本 | |

**业务规则**
- R1：项目编号全局唯一，重复时提示并阻止保存。
- R2：计划竣工日期不得早于开工日期。
- R3：项目状态为"已竣工"时才允许填写实际竣工日期。
- R4：删除项目需二次确认；存在关联设备/工序时，提示级联影响范围。

### M1-2 项目列表
- 展示：编号、名称、状态、项目经理、计划竣工、进度百分比、设备到货率。
- 筛选：按状态、按名称模糊搜索、按时间区间。
- 排序：默认按开工日期倒序，可点列头切换。
- 行操作：查看详情 / 编辑 / 删除 / 导出单项目汇总。

### M1-3 项目详情页
- 顶部信息卡：核心字段 + 状态标签 + 三个关键指标（工序完成率、设备到货率、未闭环问题数）。
- 下方 Tab：设备清单 / 工序进度 / 里程碑 / 问题记录 / 附件（可选）。

## M2 设备物料清单（BOM）

### M2-1 设备录入
| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| 所属项目 | 是 | 外键 | 选择已有项目 |
| 设备名称 | 是 | 文本 | 如"高压开关柜" |
| 规格型号 | 否 | 文本 | 如 `KYN28-12` |
| 设备编号/位号 | 否 | 文本 | 如 `AH1` |
| 品牌/厂家 | 否 | 文本 | |
| 供货商 | 否 | 文本 | |
| 单位 | 是 | 枚举 | 台/套/米/个/批 |
| 数量 | 是 | 数值 | >0 |
| 单价 | 否 | 数值 | 元，仅记录 |
| 合同到货日期 | 否 | 日期 | |
| 实际到货日期 | 否 | 日期 | |
| 到货状态 | 是 | 枚举 | 见字典 ENUM-02 |
| 验收状态 | 是 | 枚举 | 见字典 ENUM-03 |
| 存放位置 | 否 | 文本 | 仓库/现场 |
| 备注 | 否 | 长文本 | |

**业务规则**
- R5：数量必须大于 0，单价 ≥ 0。
- R6：到货状态为"已到货/部分到货"时，必须填实际到货日期。
- R7：验收状态为"合格/不合格"时，必须有到货状态"已到货"前置。
- R8：支持批量导入 Excel（模板列与上表一致），导入时按"项目+设备名称+规格型号"判重。

### M2-2 设备列表
- 按项目过滤，展示全部字段（可配置列显隐）。
- 状态色标：未到货（灰）、部分到货（橙）、已到货未验收（蓝）、验收合格（绿）、验收不合格（红）。
- 快捷筛选：仅看未到货 / 仅看不合格 / 即将到货（合同日期 ≤ 7 天）。
- 支持导出当前列表为 Excel。

| 计划结束 | 是 | 日期 | |
| 实际开始 | 否 | 日期 | |

### M3-2 进度日报（核心高频功能）
| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| 所属项目 | 是 | 外键 | |
| 所属工序 | 是 | 外键 | |
| 日期 | 是 | 日期 | 默认今天 |
| 当日完成量 | 是 | 数值 | |
| 完成单位 | 是 | 枚举 | 米/台/套/项/百分比 |
| 累计完成 | 自动 | 数值 | 系统按工序累加 |
| 天气 | 否 | 枚举 | 晴/阴/雨/雪/风 |
| 出勤人数 | 否 | 整数 | |
| 记录人 | 否 | 文本 | |
| 现场情况 | 否 | 长文本 | |

**业务规则**
- R9：同一工序同一天只允许一条日报，重复时提示"是否覆盖/追加"。
- R10：日报保存后自动重算工序的累计完成量与完成百分比。
- R11：工序完成百分比 = 累计完成量 / 计划总量（计划总量在 M3-1 中补充字段）。
- R12：当完成百分比 = 100% 时，工序状态自动置为"已完成"，实际结束日期取最后一条日报日期。

> 补充：M3-1 需增加"计划总量"字段（数值 + 单位），用于 R11 计算。

## M4 附件/图片管理

### M4-1 附件上传
**字段**

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| 所属项目 | 是 | 外键 | 自动带入 |
| 关联对象 | 否 | 枚举+外键 | 项目 / 设备 / 工序 / 问题，可挂到具体记录 |
| 文件 | 是 | 文件 | 支持批量，单文件 ≤ 50MB |
| 分类 | 是 | 枚举 | 照片 / 图纸 / 文档 / 其他，默认按扩展名自动判断 |
| 说明 | 否 | 文本 | |

**业务规则**
- R17：单文件大小 ≤ 50MB，超限提示并拒绝。
- R18：允许的扩展名白名单：jpg/jpeg/png/gif/bmp/webp/pdf/dwg/dxf/xls/xlsx/doc/docx。
- R19：文件复制到 `data/attachments/{project_id}/` 下，文件名用 UUID 重命名防冲突，原名存库。
- R20：删除附件记录时同步删除物理文件；删除项目时级联清理整个附件目录。

### M4-2 附件列表与预览
- 项目详情"附件"Tab 展示：缩略图/图标、文件名、分类、大小、上传时间、关联对象、说明。
- 图片类：点击弹层大图预览，支持左右切换。
- 图纸/文档类：点击调用系统默认程序打开。
- 支持按分类筛选、按关联对象筛选。
- 支持"打开所在文件夹"定位物理文件。

## M5 汇总统计与报表

### M5-1 项目进度汇总（首页仪表盘）
- 卡片指标：在建项目数、逾期工序数、未闭环问题数、本月到货设备数。
- 图表：
  - 各项目工序完成率条形图（按权重加权）。
  - 设备到货状态分布饼图。
  - 近 30 天日报数量趋势折线图。

### M5-2 导出功能
| 导出物 | 格式 | 内容 |
|---|---|---|
| 单项目汇总 | xlsx | 项目信息 + 工序进度 + 设备 + 问题 多 Sheet |
| 工序进度表 | xlsx | 工序、计划/实际、完成率、负责人 |
| 设备台账 | xlsx | 全部设备字段 |
| 问题台账 | xlsx | 全部问题字段 |
| 完整备份包 | zip | app.db + attachments/ 目录 |

**业务规则**
- R15：导出文件名格式：`{项目编号}_{报表名}_{YYYYMMDD}.xlsx`。
- R16：导出为纯数据，不加图表，便于二次加工。

### M5-3 数据备份
| 方式 | 触发 | 目标位置 | 保留策略 |
|---|---|---|---|
| 手动一键备份 | 用户点按钮 | 用户选定目录 | 不自动清理 |
| 定时自动备份 | 每天一次（默认 18:00，可配置） | `data/backups/` | 保留最近 30 份，超出自动清理最旧 |

**业务规则**
- R21：备份内容 = `app.db` + `attachments/` 目录，打包为 zip（仅 db 无附件时可直接为 .db）。
- R22：自动备份失败（如磁盘满）时记录日志并弹窗提醒用户，不阻塞应用。
- R23：恢复操作需二次确认并提示"当前数据将被覆盖"。

## M6 系统级需求（非功能）

| 编号 | 需求 | 验收标准 |
|---|---|---|
| N1 | 启动速度 | 冷启动 ≤ 3 秒 |
| N2 | 数据量承载 | 支持 50 个项目 / 单项目 500 设备 / 5000 条日报不卡顿 |
| N3 | 数据安全 | 数据库单文件 + 附件目录，提供手动一键备份与每日自动备份 |
| N4 | 离线可用 | 全程不联网 |
| N5 | 操作效率 | 日报录入 ≤ 5 次点击完成 |
| N6 | 容错 | 任何表单校验失败给出明确中文提示，不出现英文报错弹窗 |
| N7 | 数据校验 | 删除父级记录前提示关联数量，避免产生孤儿数据 |
