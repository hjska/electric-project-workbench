# 页面清单与交互说明

> 布局范式：左侧固定导航栏 + 顶部项目切换器 + 右侧内容区

## P0 仪表盘

**布局**：三行卡片式
- 第一行：4 个指标卡 —— 在建项目 / 逾期工序 / 未闭环问题 / 本月到货
- 第二行：左「各项目进度条形图」右「设备到货状态饼图」
- 第三行：近 30 天日报趋势折线图 + "待办问题"快捷列表

**交互**
- 点击指标卡跳转到对应筛选后的列表页（「本月到货设备」跳转物料管理 P11）。
- 图表 hover 显示数值 tooltip。
- 无数据时显示空状态引导（"还没有项目，点这里新建"）。

## P8-2 项目资料文件夹（项目详情 Tab）

**背景**：图纸、PLC 程序、说明书、试验报告等以「文件」形态存在的资料，不适合入库，
且必须放在用户能随手打开、直接往里丢文件的地方。因此每个项目在配置好的**资料根目录**
下拥有一个独立文件夹。

**文件夹命名**：`项目编号_项目名称`（编号在前，便于按工程编号排序）。
名称做 Windows 非法字符清洗，长度截断 70 字符，规避 `CON`/`NUL` 等保留设备名。

**默认结构**（两级，可在设置页编辑）

```
01-图纸/{设计图纸, 变更图纸, 竣工图纸}
02-程序/{PLC程序, 触摸屏组态, 变频器与仪表参数}
03-设备资料/{设备清单, 说明书与样本, 合格证与检测报告}
04-施工资料/{施工方案与技术交底, 现场照片, 隐蔽工程记录}
05-验收竣工/{试验报告, 验收单, 竣工资料}
06-往来文件/{收文, 发文}
99-其他/
```

**两种视图**（右上角切换）

1. **目录浏览** —— 逐层查看磁盘真实内容
   - 工具条：面包屑导航、`刷新`、`新建文件夹`、`在资源管理器中打开`
   - 列表列：名称、内容（目录显示子树文件数与占用，文件显示大小）、改动时间、创建时间、`打开/进入`、`定位`
   - 名称 / 内容 / 改动时间 / 创建时间四列均可点表头排序。
   - 目录行的「改动时间」取**子树内最近一次文件改动**：Windows 下父目录 mtime 不会因子文件
     内容变化而更新，因此显式递归统计，这样不点进去也能看出哪个分类刚动过。
   - 7 天内有改动的项标 `新` 标签并高亮。

2. **最近改动** —— 全项目扫描后按改动时间倒序
   - 列：文件、所在位置（一级分类标签 + 可点击跳转到所在目录）、大小、改动时间、`打开`/`定位`
   - 时间范围切换：全部 / 近 7 天 / 近 30 天
   - 用途：用户不走软件上传、直接在资源管理器里丢文件，隔几天回来靠这一屏定位最新资料。

**实时识别（核心行为）**
- 页签打开时通过 `folder:watch` 以 `fs.watch({ recursive: true })` 监视项目文件夹，页面标注「实时监控中」。
- 用户在资源管理器里新建 / 拖入 / 覆盖 / 删除文件 → 主进程 debounce 600ms 合并事件，
  清空扫描缓存后推送 `folder:changed`，前端自动刷新当前视图并提示变化条数。
- 引用计数管理：详情页概览与资料页签同时订阅同一项目时只挂一个系统 watcher；
  离开页面、退出应用时释放。
- 目录被整体删除 / 移动时 watcher 触发 error 自动关闭，不影响应用运行。

**统计与概览**
- `folder:stats` 递归统计：文件数、子目录数、总占用、最近改动文件与时间、近 N 天改动数、
  各一级分类明细（空分类也列出，便于看出「这块还没放东西」）。
- 结果带 4 秒 TTL 缓存；监听事件触发时立即失效，保证显示的是最新数据。
- 详情页头部以 `资料文件 N 个` 指标卡 + 「占用 / 最近改动 / 近 7 天 N 项改动」展示，随磁盘变化自动更新。

**扫描保护**：单次扫描上限 20000 个文件、深度 8 层，超限截断并标记 `truncated`，避免超大目录卡死界面。

**交互**
- 双击目录 → 进入；双击文件 → 调用系统默认程序打开。
- 面包屑可点击回退到任意层级。
- 空目录显示引导文案（"直接在资源管理器里把图纸、程序拖进来就行，软件会自动识别并显示改动时间"）。
- 路径越界（`../`）一律拒绝，防止通过 IPC 读到项目文件夹以外的地方。

**入口**
- 项目详情页右上角 `打开资料文件夹`（直接调起资源管理器）。
- 项目列表「操作」列的 `资料` 按钮。
- 项目详情头部显示当前文件夹完整路径，可一键复制。

**与「附件」（P8-1）的分工**
- 资料文件夹：用户自管的普通文件夹，软件不复制、不删除、不纳入备份，只建目录/打开/列目录。
- 附件：软件内上传登记，有分类与说明、可挂到具体记录、纳入备份。

**生命周期约定**
- 项目创建 → 自动建目录树（失败不阻断建项目，返回 `folderWarning` 由界面提示）。
- 项目编号/名称变更 → 若当前文件夹仍是自动命名，则跟随重命名；用户改过名的目录不动。
- 删除项目 → **资料文件夹一律保留**，不随项目级联删除。
- 文件夹被手动挪走/删除 → 记录失效时清空 `folder_path`，下次访问按当前根目录重建。
- 存量项目 → 设置页「为已有项目补建文件夹」批量补齐。

## P11 物料管理（跨项目汇总）

**定位**：项目内「设备清单」（P3）是单项目视角；本页是**全局视角**，同一份 `equipment` 数据。

**顶部指标条（6 个）**：物料条目 / 合计数量 / 合计金额 / 到货率（按数量）/ 逾期未到货 / 待到货验收。
「逾期未到货」「待到货验收」卡片可点击 → 直接切到对应的快捷视图。

**统一口径**（服务端 SQL 计算，总表与指标共用同一套 `WHERE`，保证两处数字永远一致）

- **逾期未到货**：有合同到货日期 且 该日期早于今天 且 到货状态 ≠「已到货」。
  无合同到货日期的物料**不计入**逾期。
- **7 天内应到货**：合同到货日期落在 `[今天, 今天+7天]` 且 尚未「已到货」。
- **待到货验收**：到货状态 ∈ {已到货, 部分到货} 且 验收状态 = 「未验收」。
- **到货率**：按**数量**加权 = 已到货数量 / 总数量。金额 = 数量 × 单价。

**Tab 1 · 物料总表**

- 快捷视图：全部 / 逾期未到货 / 7天内应到货 / 待到货验收 / 不合格。
- 筛选：项目（全项目 / 指定项目 / **日常备品**）、到货状态（多选）、验收状态（多选）、供货商、关键字
  （设备名/型号/位号/品牌/供货商/存放位置/项目名/项目编号/备品）。
- 列：所属项目（可点，跳转该项目设备清单页签；备品显示紫色标签）｜设备名称｜规格型号｜数量｜单价｜金额｜
  合同到货（带「逾期 N 天」红标签、「N 天 / 今日应到」黄标签）｜到货状态｜验收状态｜
  供货商｜品牌｜位号｜实际到货｜存放位置｜操作。数量/单价/金额/日期列可排序，
  状态列带列筛选器。
- **整行着色**：逾期未到货 → 红色；验收不合格 → 黄色。
- **写操作（不绕过业务规则）**：
  - 跨项目编辑 / 删除单条。
  - 勾选多条 → `批量改状态`（到货状态 / 验收状态，留空表示不修改）或 `批量删除`。
  - 设为「已到货 / 部分到货」未给日期时默认取今天；改回「未到货」时清空实际到货日期。
  - 每条单独跑 `validateEquipment`；不满足规则（如「未到货不能有验收结论」）的条目
    **跳过并在弹窗里逐条列出原因**，其余照常更新。
  - 新增物料：弹窗内下拉选择归属项目（可留空 = 日常备品）。
- 导出 `导出当前筛选` —— 导出当前筛选结果（含逾期天数列）。

**Tab 2 · 按项目汇总**

- 用 `LEFT JOIN` 从项目出发，**没有录物料的项目也会列出**（便于发现漏录）；
  日常备品作为一条独立分组（`id=0`）追加在末尾。
- 列：项目｜状态｜物料条目｜总数量｜总金额｜到货率（进度条，hover 显示已到货/总量）｜
  未到货｜逾期未到货｜待到货验收｜不合格｜`筛选`（切回总表并按该项目收窄）。
- 底部合计行（含备品分组）。

**Tab 3 · 按供货商汇总**（催货视角）

- 列：供货商｜涉及项目数｜物料条目｜总数量｜总金额｜未到货｜逾期未到货｜待到货验收｜不合格｜`筛选`。
- 按金额降序；只统计填了供货商的物料；底部合计行。

**日常备品（`project_id` 为空）**

- 新增/编辑弹窗的「所属项目」**非必填**，第一项即「（日常备品 · 不归属项目）」，也支持直接清空。
- 总表：备品行的「所属项目」列显示紫色 `日常备品` 标签（不可点），排序上统一沉底；
  关键字搜索支持「备品」二字命中。导出时项目名称写「（日常备品）」。
- 筛选：`所属项目` 下拉与汇总工具条均含「日常备品（不归属项目）」选项 → 只看备品。
- Tab 2 按项目汇总：备品聚合为一条独立分组（`is_common=1`，`id=0`）追加在最后，
  状态列显示 `—`，`筛选`按钮切到总表的备品视图；底部合计包含备品。
- Tab 3 按供货商汇总：`备品 N` 标签标示该供货商的备品条目数；只供应备品的供货商「涉及项目」显示 `—`。
- 指标卡：物料条目卡在存在备品时追加一行「含日常备品 N 条」；
  `project_count` **不含**备品（备品不算项目）。
- 备品同样受「归属 + 名称 + 型号」唯一约束；批量改状态对备品同样走 `validateEquipment`。

**口径隔离**：汇总页签只接受「项目 / 备品」这一个维度，其工具条仅保留归属下拉 + 刷新，
并提示「按当前归属口径统计」——避免总表的快捷视图/状态筛选残留在汇总页造成口径矛盾。

**入口**：左侧导航 `物料管理`；仪表盘「本月到货设备」卡片。

## P9 数据备份/恢复

- 显示当前数据库路径、文件大小、附件目录大小、最后备份时间、下次自动备份时间。
- 备份设置：自动备份开关、执行时间（默认 18:00）、保留份数（默认 30）、备份目录。
- 按钮：`立即备份`（选择目录）、`从备份恢复`（选择 .db 或 .zip，二次确认警告）。
- 显示历史备份列表（读取备份目录，含时间、大小、类型），支持删除旧备份。
- 一键"打包完整备份（含附件）"。

## 通用交互规范

| 场景 | 规范 |
|---|---|
| 表单校验失败 | 字段下方红字提示，滚动定位到首个错误字段 |
| 删除操作 | 一律二次确认，显示将被删除的记录数 |
| 保存成功 | 右上角 toast，2 秒自动消失 |
| 加载中 | 表格骨架屏，按钮禁用 + loading 态 |
| 空状态 | 居中插画 + 引导文案 + 操作按钮 |
| 数字精度 | 数量保留 2 位小数，金额保留 2 位小数 |
| 日期格式 | 一律 `YYYY-MM-DD` 显示 |
| 错误兜底 | 捕获异常并提示中文，禁止白屏与英文堆栈 |
