# 电气项目管理台 — 需求文档包

> 版本：v1.0 ｜ 日期：2026-10-10 ｜ 形态：单机桌面应用 ｜ 数据：本地 SQLite

## 1. 项目定位

面向电气工程项目的**单机现场管理工具**，在一台电脑上完成项目台账、设备物料、施工进度、成本合同四大板块的记录、跟踪与统计。不依赖网络、不依赖服务器，数据落在本地文件，可整包拷贝迁移。

## 2. 已确认的边界（用户选择）

| 决策项 | 选择 | 说明 |
|---|---|---|
| 业务范围 | 1A+1B+1C | 项目台账 + 设备物料清单 + 施工进度工序（**不含**成本/合同付款） |
| 附加模块 | 附件/图片管理 | 现场照片、图纸等，文件存文件系统不入库 |
| 数据存储 | 2B | 本地 SQLite 单文件数据库 + 附件目录 |
| 数据备份 | 手动 + 定时 | 手动一键备份 + 每日自动备份（保留最近 30 份） |
| 交付形态 | 3C | 桌面应用，最终打包为 exe，双击运行 |
| 使用人数 | 单人单机 | 无并发、无权限体系、无登录 |

## 3. 核心使用场景

1. **开工阶段**：新建项目，录入项目基本信息、参建单位、合同额（仅作字段记录）。
2. **备料阶段**：按设备/物料清单（BOM）录入设备，跟踪采购、到货、开箱验收状态。
3. **施工阶段**：把工程拆成工序/节点，按天记录完成量、负责人、问题，跟踪里程碑。
4. **留痕阶段**：上传现场照片、图纸等附件，挂到项目或具体设备/工序/问题上。
5. **汇报阶段**：一键导出项目进度汇总表（Excel）和问题台账，用于内部汇报。

## 5. 术语表

- **项目（Project）**：一个电气工程标的，如"XX 厂 3# 配电室改造"。
- **设备（Equipment）**：项目下的具体设备/物料条目，如"高压开关柜 KYN28-12"。
- **工序（Process）**：施工分解单元，如"基础浇筑""柜体就位""二次接线"。
- **节点/里程碑（Milestone）**：有明确日期的关键事件，如"送电验收"。
- **问题（Issue）**：施工过程中产生的异常、待办、缺陷记录。
